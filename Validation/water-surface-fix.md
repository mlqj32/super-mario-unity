# 水关游出水面修复

已复现。旧逻辑把脚底坐标限制在 176，却没有计入人物高度，因此小马里奥的头部仍可到达 192，大／火焰形态到达 208，进入画面顶部的 HUD 区域。部分水关入口也从 176 或 192 的脚底高度开始，第一帧就在边界外。

现在上边界约束人物头部：小形态脚底最高为 160，大／火焰形态为 144。水关载入、正常移动后、拾取道具改变形态后均应用这一限制，只取消越界时的向上速度，保留下沉速度。道具变大后的第一帧也会修正，避免在变身暂停期间停留在水面上方。

水管传送沿原来的路径移动；死亡动画和陆地跳跃不受此水面限制。边界高度与参考关卡中水面阻挡物的下缘 176 一致。

验证入口：Unity 菜单 **Mario → Validate swimming surface**，或批处理 `-executeMethod MarioWaterValidation.Run`。

- 修复前：440 项检查中 214 项失败，记录见 [复现结果](WaterSurface/before-checks.txt)。
- 修复后：水面专项和既有玩法边界回归共 **502 项全部通过**，见 [检查记录](WaterSurface/checks.txt)。
- 覆盖全部 11 个水关入口，三种形态、两种操作模式、连续划水、松键下沉、向上冲量、暂停、吃蘑菇变大、水管进出、死亡和陆地跳跃。
- 64 个可编辑关卡资源的序列化数据保持不变。

大形态实际渲染截图：[2-2 修复前](WaterSurface/2-2-power2-before.png) / [修复后](WaterSurface/2-2-power2-after.png)，[日版 3-2 修复前](WaterSurface/J-3-2-power2-before.png) / [修复后](WaterSurface/J-3-2-power2-after.png)。
