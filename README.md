# 超级马里奥 · 原生 Unity 复刻工程

Unity **6000.3.15f1**。工程根目录就是本文件所在目录，可通过 Unity Hub 的 **Add project from disk** 添加。

## 开始运行

- 编辑器：打开 `Assets/Scenes/Main.unity`，点击 Play。
- Windows：运行 `Builds/Windows/超级马里奥.exe`，同目录的数据文件不可分开移动。仅保留这一个最新构建，包含此前所有修复。
- 标题页选择 **初代 / 日版二代 / 猫里奥**，点击 **开始游戏** 从对应作品第一关开始；**选择关卡** 可直接进入任意一关。现共 **68 关**：32 + 32 + 猫里奥原版 4 关。
- 标题页或暂停菜单点击 **设置**：调整总音量、静音、全屏／窗口、铺满／原始比例和小窗／标准／大窗。自动保存，下次启动继续使用。
- 设置新增 **自动加速**（默认关闭）：开启后初代／日版二代的方向键或摇杆移动即进入跑速，无需长按加速键；火球仍由原开火按键触发。鼠标点击或确认键切换，左右键也可关闭／开启，退出游戏后保留选择。猫里奥没有独立的走／跑键，方向输入本身一直使用原版加速曲线，因此该选项在猫里奥中置灰并显示“方向键使用原版自动加速”。验证见 [自动加速说明](Validation/auto-run.md)。
- 默认无边框全屏，画面保持原始 256×240 比例，宽屏两侧留边。窗口三档为 512×480、768×720（标准）、1024×960，屏幕较小时等比缩小；普通窗口无需为比例留边。旧版“铺满”偏好首次升级时自动改为原始比例，之后手动选择仍会保存。可在设置中自行启用拉伸铺满。Windows 窗口禁止边框自由拖拽缩放，保留最大化、还原、标题栏双击最大化。
- 三部作品新游戏／选关均为 **10 条生命**；死亡扣一条，手动重玩本关保留当前生命。猫里奥保留负命数继续重试的原版规则，不因命数归零强制结束。
- 默认启用响应优化：约 150ms 跳跃预输入、100ms 离地宽限、落地立即响应。参考蔚蓝的主动制动思路，满速松开方向后地面约 100ms、空中约 150ms 停稳；关闭自动加速时，空中松开加速键会降回走速。起步仍约 300ms 到速度上限。短按低跳、长按高跳；持续按住不会落地自动连跳。详情见 [操作手感报告](Validation/controls-feel.md)。

炮台和食人花专项修复见 [核查报告](Validation/cannon-piranha-fix.md)。Mario Forever 与 SMB3 的原生接入条件和系统差异见 [扩展可行性评估](Validation/expansion-feasibility.md)，这两部作品尚未加入当前关卡列表。

1-2 等关卡循环升降平台的瞬移问题及双向搭乘回归见 [升降平台修复报告](Validation/platform-elevator-fix.md)。

弹簧现在会压缩、回弹后自动发射；落地前预输入或压缩时按跳跃可加强弹跳，支持越过 2-1 旁的高墙。验证见 [弹簧修复报告](Validation/spring-fix.md)。

通关会等待通关音乐、时间奖励结算和烟花全部结束，再进入下一关；切关、重开和返回标题会清理旧音轨，避免通关音乐与下一关背景音乐重叠。验证见 [通关音频报告](Validation/finish-audio-fix.md)。

拔旗后从旗台落地并正常行走，到实际城堡门口后停止、隐藏，再等待通关流程完成。初代和日版的地面城堡门均有专项验证，避免跳跃姿势平移或穿过城堡，详见 [城堡入口修复报告](Validation/castle-entry-fix.md)。

日版二代旗杆重复绘制、杆身穿出杆顶的问题已修复，游戏和关卡编辑器预览均使用地图原有旗杆图案。已包含在标准 Windows 包中，检查记录见 [旗杆绘制修复报告](Validation/flagpole-render-fix.md)。

双平台天平的竖绳现在随平台升降同步伸缩，断绳后保留悬挂的绳段。553 项专项及回归检查通过，详见 [平衡绳线修复报告](Validation/scale-rope-fix.md)。标准 `Builds/Windows` 包包含本次绳线修复和上一轮旗杆修复。

水关现在按人物头部限制上浮，修复小／大形态游出水面、入口出生越界及水面附近变大后越界的问题。全部 11 个水关入口及水管传送等 502 项检查通过，详见 [水面边界修复报告](Validation/water-surface-fix.md)，已包含在标准 Windows 包中。

初代水关补回导入时遗漏的深蓝水体和顶部白色波纹，编辑器预览同步修正。644 项检查通过，详见 [水关背景修复报告](Validation/water-background-fix.md)。最新包统一为 `Builds/Windows/超级马里奥.exe`，包含此前所有修复。

## 内容与实现

- 猫里奥为 Chiku 原版的 **4 关、8 个区域**，采用公开 C# 移植源码适配 Unity；独立 30 Hz 逻辑与 480×420 原始画面，保留陷阱、隐藏砖、地下区域、检查点、关卡顺序和结局。方向移动、Z／空格／手柄 A 跳跃，提示框按确认关闭；暂停、重开、设置和选关共用当前菜单。未接入随机地图模式或第三方续关。数据位于 `Assets/Resources/Syobon/Stages/*.csv`；详细来源、编辑方式与测试范围见 [猫里奥接入报告](Validation/syobon-integration.md)。
- 初代和日版二代各 1-1 至 8-4，**共 64 个独立可编辑 LevelData 资源**。初代 ID 为 `1-1` 等，日版二代为 `J-1-1` 等；各自的 8-4 独立结局。
- 日版二代从原始反汇编数据离线提取逐格地形，使用原版日版地形贴图；原生节点包含毒蘑菇、倒挂食人花、风区、管道、奖励区与迷宫门。没有复制初代地图凑关数。不包含世界 9 和 A–D。
- 初代保留 **63 个区域、8,444 个参考对象**，含地下奖励区、天空区、水下、Warp Zone、水管/藤蔓连接，以及 4-4、7-4、8-4 的分段迷宫数据。
- HUD、标题、暂停、选关、结局和世界内提示使用中文。旧字体不含汉字，已补充外观相近的 Fusion Pixel 12px 中文像素字体，并保留原版数字。
- 顶金币砖生成独立的旋转弹出效果，HUD 绘制金币图标；效果不重复计分，也不会参与敌人碰撞。
- 小/大/火焰形态、蘑菇、火花、星星、1UP、金币、砖块、隐藏砖、龟壳、移动平台、弹簧、食人花、锤子兄弟、Lakitu、火棒、库巴、旗杆和结局流程。
- C# 原生逻辑、SpriteRenderer 像素显示、独立 AABB 碰撞，不依赖浏览器或 NES 模拟器。
- 256×240 渲染，Point 采样，默认原始比例，可选拉伸铺满；NTSC **60.0988138974405 Hz** 固定逻辑步进，渲染与逻辑分离。
- 横向速度使用整数累加，位置量化至 1/16 像素；走速 1.5、跑速 2.5 像素/逻辑帧。跳跃保留原版速度分档、上升/下落重力表，默认增加预输入和离地宽限；严格原始模式可在 Inspector 取消 Responsive Controls。
- 渲染使用单一 LateUpdate 相机提交点、Point 采样和垂直同步，避免 RenderTexture 在 GUI 重绘期间被读取到半帧。
- 移动物体统一按相对相机的位置取整，消除跟随时的单像素左右抖动；跑步动画以独立逻辑计时连续推进，走跑切换不会倒序或跳帧。连续 576 帧整画面像素核查见 [移动画面报告](Validation/player-motion-fix.md)。
- 火球、火焰花、星星、锤子、城堡火球和金币补齐四帧动画；Mario 发射火球、Cheep-Cheep、Blooper、Hammer Bro 和 Bowser 的特殊姿态也有独立状态。

死亡时点击“立即复活”，或按回车、空格、Z、R（手柄 A/Start）可跳过死亡动画，扣一条命后以小马里奥从检查点复活；最后一条命则进入游戏结束。也可以不操作，等待动画结束。暂停菜单的“重玩本关”会弹窗确认，默认选中取消，左右键选择、回车确认、ESC 取消；确认后从本关起点以小马里奥开始，保留分数、金币和生命。验证见 [重开功能报告](Validation/restart-fix.md)。

最新火球爆炸、金币／得分特效、碎片、烟花和 17 只库巴／火焰检查见 [特效核查报告](Validation/effects-bowser-audit.md)。画面铺满、音量与窗口控制见 [显示设置报告](Validation/display-settings.md)；食人花修复见 [食人花报告](Validation/piranha-fix.md)；朱盖姆修复见 [追踪报告](Validation/lakitu-fix.md)；金币、中文与64关验证见 [扩展报告](Validation/coin-chinese-japan-fix.md)。

## 编辑关卡

最新系统核查修复龟壳再次踩踏不启动等 19 类问题，864 项 Unity 验证及 Windows 实际 Player 新增 361 项玩法检查通过。完整清单、覆盖范围和证据见 [玩法核查报告](Validation/gameplay-audit-fix.md)。之前的人物与城堡动画修复见 [动画修复报告](Validation/castle-animation-fix.md)。

1. Unity 菜单 **Mario → Level Editor**。
2. 选择作品、世界、关卡和区域。
3. 点击 **生成场景预览**，在 Scene 视图移动原生对象，在 Inspector 编辑 `Node` 属性。
4. 点击 **应用场景编辑到关卡** 保存。删除预览对象后应用可删除对应对象；可使用窗口中的添加砖块按钮。
5. 点击 **试玩本关**。

关卡资源在 `Assets/Resources/Levels`。Inspector 中可直接修改时间、传送入口和城堡 `sections`；`x` 为左边，`y` 为上边，单位是原版像素，地面高度为 0。参考 JSON 在 `Assets/Resources/LevelData`。

验证不会覆盖关卡编辑。**Restore reference levels** 是显式恢复操作，会覆盖所有关卡编辑，并在菜单中确认。

## 验证与可复现构建

- **Mario → Validate project and gameplay**：结构、资源、传送、移动、道具、换关、结局和 64 关运行压力检查。
- **Mario → Build Windows player**：输出到 `Builds/Windows`。
- `Tools/validate-project.py`：Unity YAML 文档、GUID 和本地对象引用检查（Python + PyYAML）。
- `Tools/import-reference.cjs`：从随工程保存的参考数据重新导出关卡 JSON 和像素 PNG（Node.js）。
- `Tools/import-font.py`：重新导出 8×8 字体（Python + Pillow）。
- `Tools/import-coin-frames.py`：从原版 CHR 重建金色旋转金币四帧，参考导入工具也会自动调用。
- `Tools/import-chinese-font.py`：检查中文字符覆盖并生成 12×12 字形（Pillow + fontTools）。
- `Tools/assemble-smb2j-reference.py` / `Tools/import-smb2j.py`：离线转换日版二代参考数据（ca65 + py65）。普通导入 `ProjectSetup.ImportJapanese` 只添加缺少的资源，不覆盖编辑。显式命令行参数 `-mario-refresh-japan-reference` 才会恢复日版二代资源。
- `results.json` 记录最近一次 Unity 检查；最新显示设置的实际 Windows 验证与截图见 [`Validation/display-settings.md`](Validation/display-settings.md)，既有运动参考说明见 [`Validation/README.md`](Validation/README.md)。

## 当前精度边界

初代 4-4 的路线为第一段上层、第二段最底层。已修正第一段断口后的错误路线判定；复现过程和 54 项回归范围见 [`Validation/maze-4-4-fix.md`](Validation/maze-4-4-fix.md)。

这是可运行、可编辑的原生复刻版本，**不是已经证明与 NES 原版逐帧一致的完成品**。初代关卡来源是 FullScreenMario 的 32 关描述；日版二代的地形来自原始区域解析器，敌人和传送流转换为原生节点。二代的迷宫判定、动态机关、敌人时序仍需逐关对照实机校准，不能把静态地图解析准确等同于整款游戏逐帧一致。

原始运动模式保留独立参考轨迹对比：调用 SMB-Vanilla 的 SMB1 运动子程序生成 12 组、共 2,160 帧输入/位置记录，覆盖走路、跑步、刹车、反向、空中转向、短跳、长跳、起跑同时跳跃和中途重新按跳。此测试针对关闭响应优化的底层电机，在统一平地约束下位置误差为 **0 像素**，**不包含 NES 整机时序或原版场景碰撞**。默认游戏现在启用输入容错和响应优化，轨迹会有意不同，不将原始模式的零误差结论用于默认玩法。可在 MarioGame Inspector 中取消 Responsive Controls 切回原始运动模式。原始记录、差分和说明保存在 `Validation`。

敌人 AI、出生/休眠时机、碰撞边角、弹簧、天平、计时器与奖励计分仍属于原生近似实现；未复刻全部原版漏洞、硬件延迟和完整多人模式。尚未逐关人工通关验收。运行压力测试是稳定性测试，不代表 64 关均已由机器人正常通关，也不包含二代 Luigi 独立物理。

来源及随附许可文本见 `ThirdParty/NOTICE.md`。本工程没有修改旁边的 LuoWei 工程代码。

怪物尸体中途消失已修复：下落尸体完全离开画面后清理，并与水管及爆炸特效正确分层；踩扁板栗仔保留短暂消失效果。155 项专项回归的范围与证据见 [`Validation/corpse-fix.md`](Validation/corpse-fix.md)。

跳跃擦边受伤判定已放宽：受伤框与踩头、地形框分离，轻微擦边不扣血，下降踩头保留较宽范围。295 项专项回归及调整参数见 [`Validation/contact-hitbox-fix.md`](Validation/contact-hitbox-fix.md)。
